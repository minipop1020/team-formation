# AI 모델 시험 기록 

AI 배정에 쓸 무료 모델을 고르려고, 앱의 AI 호출 코드(`tf/ai.py`)로 오픈라우터 무료 모델을 직접 불러 본 기록이다.
아래 출력은 시험 스크립트의 실행 결과를 그대로 옮긴 것이다(앱 화면이 아니라 시험 스크립트의 출력).

## 시험 1: 처음 정한 1차, 2차, 3차 모델 (max_tokens 6000, 어려움 문제)

```
1차 nvidia/nemotron-3.5-super-vl:free: 응답 28.0초, 검사 통과
2차 nvidia/nemotron-3-ultra-550b-a55b:free: 실패 91.2초 - AIFailure: 응답 형식이 올바르지 않음
3차 cohere/north-mini-code:free: 실패 86.7초 - AIFailure: 빈 응답
```

→ 2차, 3차 모델이 실패해서 다른 모델을 찾기로 함

## 시험 2: 다른 무료 모델 후보 6개 (max_tokens 6000, 어려움 문제, 동시에 부름)

```
nvidia/nemotron-3.5-lightning:free: 실패 65.1초 - 빈 응답
google/gemma-4-31b-it:free: 실패 1.0초 - HTTP 429 Provider returned error
google/gemma-4-26b-a4b-it:free: 실패 1.0초 - HTTP 429 Provider returned error
dots-studio/dots-3-note-preview:free: 실패 72.1초 - 빈 응답
xingchen-agi/xing4.0-29b-a4b:free: 실패 7.0초 - 응답 형식이 올바르지 않음
recursive/flint-v1.0:free: 실패 1.5초 - HTTP 503 Provider returned error
```

→ 6개 모두 실패. 모델 탓으로 보기 전에 응답 원문을 열어 보기로 함

→ 작은 문제에서는 정답을 냄. 답하기 전에 생각(reasoning)에 수천 토큰을 쓰고 있었음

## 시험 4: 응답 길이 한도를 16000으로 늘려 다시 (어려움 문제)

```
nvidia/nemotron-3.5-lightning:free: 124s finish=stop tokens=14067 reasoning_len=34271 → 검사 실패
nvidia/nemotron-3-ultra-550b-a55b:free: 395s finish=stop tokens=7424 reasoning_len=18497 → 검사 통과
dots-studio/dots-3-note-preview:free: 74s finish=stop tokens=7042 reasoning_len=16091 → 검사 통과
```

→ 빈 응답의 원인은 max_tokens 6000이 생각하는 데 다 쓰인 것이었음.
lightning 은 규칙을 어긴 배정안을 내서 앱의 검사가 걸러 냄(검사 실패). ultra 는 맞았지만 395초로 120초 제한을 크게 넘음

## 시험 6: 바꾼 설정으로 앱의 1차 → 2차 → 3차 처리를 그대로 실행 (어려움 문제)

```

결과: 1차 모델(nvidia/nemotron-3.5-super-vl:free)의 배정안 / 검사: 통과
```
